## Activation GitHub Pages (une fois)

Si `https://pel-source.github.io/PEL-STUDIO-LEGAL/` renvoie 404 :

1. Ouvrir [Settings → Pages](https://github.com/PEL-source/PEL-STUDIO-LEGAL/settings/pages).
2. **Source** : *Deploy from a branch* → branche `main` → dossier `/` (root) → **Save**  
   *ou* **Source** : *GitHub Actions* (workflow `.github/workflows/pages.yml`).
3. Attendre le statut vert, puis vérifier  
   `https://pel-source.github.io/PEL-STUDIO-LEGAL/demineur/confidentialite/`.
