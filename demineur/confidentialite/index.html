Politique de confidentialité — Démineur Mobile

Dernière mise à jour : 19 novembre 2026

1. Qui est responsable ?
PEL Studio, identité éditoriale de l’entreprise individuelle PERIO (SIREN 804 772 218), 266 rue Nationale, 59800 Lille, France, édite l’application Démineur Mobile.

2. Périmètre de cette politique
Cette politique décrit le traitement des informations dans la version actuelle de Démineur Mobile, telle qu’audité dans le code de l’application :
• application Flutter ;
• fonctionnement principalement hors ligne ;
• absence de compte utilisateur ;
• absence de backend exploité par PEL Studio ;
• absence de publicité et de SDK publicitaire ;
• absence d’achat intégré ;
• dépendances limitées au SDK Flutter, à intl, cupertino_icons, shared_preferences et url_launcher (cette dernière sert uniquement à ouvrir les liens e-mail mailto: et la politique de confidentialité dans le navigateur externe).

3. Quelles informations sont enregistrées sur l’appareil ?
L’application enregistre localement, via le stockage du système (SharedPreferences), notamment :
• des préférences d’interface (sons, vibrations, mode de contrôle, préférence de langue) ;
• un profil de progression du jeu (expérience, statistiques de parties, défis quotidiens, séries, badges et récompenses débloqués, éléments d’équipement cosmétique, identifiants techniques de parties déjà traitées pour éviter les doubles comptages).

Ces informations sont liées à l’usage du jeu sur l’appareil. Elles ne permettent pas, par elles-mêmes, d’identifier nominalement l’utilisateur auprès de PEL Studio, dès lors qu’aucune transmission à PEL Studio n’est effectuée dans la version actuelle.

4. Finalités
Les données locales servent exclusivement à :
• faire fonctionner le jeu (progression, défis, statistiques) ;
• mémoriser les choix d’interface de l’utilisateur ;
• assurer la continuité de l’expérience entre deux ouvertures de l’application.

5. Destinataires et transmissions
Dans la version actuelle du code :
• aucune donnée de jeu ou de préférence n’est envoyée à des serveurs de PEL Studio ;
• aucun service d’analytique, de publicité, de paiement ou de compte n’est intégré ;
• l’application ne déclare pas de permission INTERNET dans sa configuration Android de production (release).

Des sauvegardes éventuelles du système d’exploitation (copie de sécurité de l’appareil, transfert vers un nouveau téléphone, etc.) peuvent dupliquer le stockage local hors du contrôle direct de PEL Studio.

6. Durée de conservation
Les informations restent sur l’appareil tant que l’application est installée, ou jusqu’à leur effacement par l’utilisateur (réinitialisation des données de l’application, désinstallation, ou mécanismes internes de réinitialisation lorsqu’ils existent). PEL Studio ne conserve pas de copie distante de ces données dans la version actuelle.

7. Bases et droits
Selon la nature des informations et le droit applicable, l’utilisateur dispose le cas échéant de droits d’accès, de rectification, d’effacement, de limitation et d’opposition. Pour les exercer concernant Démineur Mobile, contactez PEL Studio / PERIO par courriel à contact.predatorelevenleague@gmail.com ou par voie postale à l’adresse indiquée ci-dessus. Vous pouvez également supprimer les données locales en effaçant les données de l’application ou en désinstallant l’application.

8. Sécurité
Les données sont stockées dans l’espace de stockage privé de l’application sur l’appareil. La sécurité dépend notamment des protections du système d’exploitation et des pratiques de l’utilisateur.

9. Évolutions
Si des fonctionnalités futures (compte, synchronisation, publicité, achats, mesure d’audience, etc.) étaient ajoutées, la présente politique serait mise à jour avant leur activation.
